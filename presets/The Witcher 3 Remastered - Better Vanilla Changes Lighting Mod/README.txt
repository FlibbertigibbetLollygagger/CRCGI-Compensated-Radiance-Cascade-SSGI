Update v2: Added "The Witcher 3 Remastered - BCVLM - CRCGI v2 subtle.ini", the v1.5 subtle preset on the v2 shader. The values you tuned are kept; values the preset left at the old defaults, and the denoise, jitter and adaptive-ray settings (their meaning changed with the new filtering stack), take the v2 defaults, which are the v1.6 tuning. Crevice Light Bounce Bias is now Shadow Amount with the sign turned round (the value is converted, more = darker), and the new Shadow Contact Bias is 0.5, so the denoised escape shadow of the cascades and the contact march overlap. Move Shadow Contact Bias to 0 for the softest and cheapest shadow (the full-resolution contact passes are skipped). The bounce shaping (saturation, colour filters) no longer feeds back into the multibounce, so single-coloured rooms (the red cabaret, orange palace interiors) no longer run away.

Update v1.5: Added "The Witcher 3 Remastered - BCVLM - CRCGI v1.5 subtle.ini", the same values as the v1.2 preset on the v1.5 shader (only the section and technique names point at CRCGI_v1.5.fx). Contact shadowing note: these presets use a negative Crevice Light Bounce Bias, and in v1.5 that also darkens the game's own image in crevices (65% of the contact factor) and takes the cascades' visibility into account, so crevices and corners are darker than on older versions. The values are untouched, move the bias towards 0 if it's too much for you.
